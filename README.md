# Straiker Homebrew tap

```sh
brew install straiker-ai/tap/ascend-tunnel
```

| Package | What it is |
|---|---|
| `ascend-tunnel` | The [Ascend Tunnel](https://github.com/straiker-ai/ascend-tunnel) agent (macOS) |

The `ascend-tunnel` binary isn't notarized yet, so the cask removes macOS's quarantine flag on install. Without that, macOS blocks it on first run.
